Electricity cost guide

Mini-Split Electricity Cost

Mini-split heat pumps often use inverter-driven compressors, which means power draw can change instead of staying at one fixed value.

Do not treat maximum input as average input

If the specification only gives a maximum electrical input, using that figure for every scheduled hour can overstate typical energy use. Measured kWh or a realistic average draw is better.

Build scenarios

Try the same wattage and rate with different duty-cycle assumptions. That makes uncertainty visible and avoids pretending the calculator knows your exact climate, room load or thermostat behavior.

Use measured data when possible

A utility interval meter, whole-home monitor or suitable submeter can provide a better consumption input than a generic wattage estimate.
