Electric Dryer Cost per Load Calculator

Estimate an electric dryer's running cost from energy per load instead of assuming the heating element stays at maximum wattage for the entire cycle.

Use measured kWh or product information when available.

Formula

Cost per load = kWh per load × electricity rate. Weekly, monthly and annual estimates scale from the number of loads you enter.

Electricity-price presets: EIA Table 5.6.A, June 2026.

Cycle energy varies with load size, moisture level, temperature setting, dryer type and sensor controls. The default 3.3 kWh/load is an editable example, not a universal value.
