About WattCalc

WattCalc is a calculator-first home-energy resource built around a simple idea: a cost estimate should show the assumptions that create it.

What we publish

We create electricity cost calculators and short guides for common household loads. Where a device cycles or changes speed, we expose that uncertainty instead of presenting one generic number as universal.

Sources

We prioritize U.S. government and standards sources such as EIA, DOE and ENERGY STAR, plus model-specific product data when relevant.

Corrections

If you spot a calculation or source issue, you can open a public issue in the WattCalc GitHub repository. We prefer corrections that include a primary source or reproducible calculation.

Independence

Current calculator results do not depend on paid placement. If advertising or affiliate relationships are added later, disclosures will be added where required.
